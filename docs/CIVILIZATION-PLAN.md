## 页面与权威状态

- `/ai-town/`：PixiJS 全屏观察入口；悬浮日期、时代、运行控制、工作台入口、地图工具与定位。详情可关闭。
- `/ai-town/workbench/?world=…&tab=…`：独立管理页面，保留原有全部管理面板；直接访问、刷新、返回有效。
- `/ai-town/?view=town`：保留原聊天小镇。

使用现有 Vite 基础路径与原生 URL / History API，无新增路由依赖。世界 ID 在 URL 中优先，其次是本机选择；地图位置与缩放按世界保存在 localStorage。无明确选择时不会自动进入演示世界。创建仅由表单提交 mutation 执行，页面挂载与订阅没有创建或结算副作用。

两页直接订阅相同的 Convex 文档。时钟只由服务端调度推进，每个世界的 loop 版本使旧调度失效，数据库事务处理多个标签页的竞争；浏览器数量不影响推进次数。`recover` 只替换过期调度，旧任务因 loop 不符退出。

## 时钟与行动阶段

`clock.ts` 管理倍率、每日本位秒数和有界心跳；`engine.ts` 执行小时与日终规则。默认 1×=现实 120 秒/模拟天，24 个模拟小时，因此每 5 次在线心跳执行 1 个小时阶段。默认基准可在工作台设为 24–3600 秒/天，修改留审计。

选择 120 秒的依据：1 格移动有约 5 秒观察窗口；数十个人日的工程可在正常观察中持续出现变化，同时人物仍需要走到资源点、工作、携带并运回。它是抽象模拟比例，不是历史或真实人体劳动参数。

每小时处理移动、采集、搬运、现场劳动、照料、制作与教学参与；量化产出、劳动、疲劳与工具消耗按 1/24 日缩放。公共库存仅接收已运回物资；账本等式包括人物携带，死亡遗失物资计入损耗。分数数量使用补偿求和，降低长程累计误差。

日终处理食物消费、疾病、成长、生育、死亡、建筑磨损、食物腐败与采样。自然资源按日再生；作物有 90 天实际等待时间，播种与收获需要人物到场。日内生产并非完整的生理昼夜模型。

倍率选项为 1/5/7/30/60/120/600/3600×。每次心跳最多执行 72 个小时，达到上限显示限量推进。工作台的暂停步进为 1 天，避免将长程推进塞进单次事务。超出计算能力的请求会减慢，不积累无限追赶队列，也不会跳过资源与劳动过程。实际速度还受事务和模型负载影响。心跳按完成后再次调度，不承诺严格墙钟计时。

不使用“现在减去上次运行时间”追算。预算小数、当前小时、倍率、本位秒数和运行状态均保存。2026-10-27 起，重启或重连不得恢复过期观察；需重新手动继续。暂停阻止模拟行动并使在途模型提交失效，不在暂停中写入新提案或产生成果。完整观察与暂停规则见 [CIVILIZATION-AUTO-PAUSE.md](./CIVILIZATION-AUTO-PAUSE.md)。

## 兼容与因果

旧存档新增字段均可选，读取不会重写身份、日期、随机状态、历史或库存；第一次控制或运行时补齐时钟。已有整数倍率保留，界面按新的倍速语义显示。旧档从下次推进采用新的小时规则，未来轨迹可能不同，已发生历史不改写。原建筑的位置与类型保持；新增使用计数只表示本轮之后记录到的使用，不能倒推旧行为。

新时代由现存住所覆盖、耕作知识、真实农业产出、储藏知识和议事组织共同判定，允许退回；不由固定年份触发。新世界仍只有 160 食物与基础采集、协作、简易制作能力，无现成建筑、农田、工具、集体知识和制度。

建筑开工后支付材料，按实际劳动进度显示材料/地基/框架/墙体/封顶，完成后才提供用途。工坊作为工具与试验场所提供 15% 到场劳动效率；学舍需要教师学生到场，扩大单次传授容量；住所和粮仓保留原有生存与储藏作用。施工失败与倒塌保留有界遗址和完整归档记录。

模型接口仍只接受候选行动、简短理由和权限允许的方向建议；没有通用世界补丁接口。长期贯彻的方向锁、迟到结果版本检查、模型来源记录、人工干预账本与审计保持有效。

# 文明模拟改造：架构与验收

## 当前环境（2026-10-26）
React 18、TypeScript 5、PixiJS 7、Convex 1.41；Windows Node 24.21.0，npm 11.19.0。现有 Ollama qwen3.5:4b 与 embeddinggemma:300m。E 盘可用约 36 GiB，复用现有依赖，无新模型下载。

备份：E:/AI_town/backups/before-civilization-20261026-01。包含代码、未提交改动、Git bundle、完整 .convex 数据；database-hashes.json 记录原库与备份库相同 SHA256。恢复前停止启动器，将 project 内相应文件复制回项目；恢复旧模式代码时先另存当前改造，不删除新世界。原表不做破坏性迁移。

## 能力边界与顺序
1. `convex/civilization/`：无网络的确定性纯规则核心，PRNG 状态随存档保存。一天是最小结算单位，一年 360 天。初始化不放置人类建筑。策略为行动权重与生态约束，不是产出加成。计划经历提议、计划、执行、完成/失败。
2. `convex/civilization.ts`、`civilizationAI.ts`：新增表与事务持久化、调度、模型队列。仅服务端推进；多标签页不重复计时。决策租约及设置版本检查防止迟到输出改变新策略。记录归档、人物终身身份保留。
3. `src/civilization/`：像素地形观察台，地图、资源、人物、家谱、计划和时间线订阅同一个权威状态。原 App 保留为 LegacyTown，可通过入口访问。
4. 验证资源守恒、策略锁、生命周期、不可凭空完成、干预审计、存档恢复、跨策略对照、Windows 启停和浏览器中英文。

## 状态与执行
世界持有 seed/rng/day、地形与有限资源、人物、库存账本、施工计划、技术、制度、策略、独立模式、审计和统计。建设先支付成本并留下在建实体，人物到达工地劳动后增加进度；死亡与拒绝参与会减少劳动。失败材料不退还。农业需要可耕地、播种劳动与生长时间。技术需材料、试验与劳动，有失败概率；知识依赖传授者和教学生效，失传后不再享有知识条件。

模型只返回候选行动 ID、理由与可选策略建议。不接收人口、库存、建筑或任意世界补丁。候选项经规则再验证。模型每个重要节点最多尝试两次，超时回退并记来源，绝不为高频移动调用模型。人工与混合模式将指定重大节点挂起为明确待决事项，普通日常继续，不弹窗；AI 自主持续处理。

## 长期运行
早期阶段观察期限可选，文明灭绝自动停止；没有预设年代/科技结局。当时后端在线且运行时推进、关闭页面仍可运行；此行为已被 2026-10-27 的无人观察自动暂停替代。进程退出后不补算离线时间。时间加速执行实际规则。人口达到上限时抑制出生并显示限制。已故人物与旧记录归档到独立表，状态保留最近记录；单文档限长不等于底层存储容量有界。多个世界逐个限量调度，限制同时运行数量。
