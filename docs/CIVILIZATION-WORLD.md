# 专属文明世界（2026-10-26）

主入口为 `/ai-town/`，工作台为 `/ai-town/workbench/`，旧聊天小镇为 `/ai-town/?view=town`。文明世界不使用旧小镇的固定地图、角色身份或聊天行为。只复用原项目人物与植物像素美术；文明地形、资源、建筑与行为由独立渲染器组织。

## 状态与世界表现

| 工作台状态 | 世界表现与追溯 |
|---|---|
| 地块地形、水域、资源、肥力、季节 | 岸线、林木密度与大小、幼树/树桩、矿石与采空地、食物植被、季节色；点击查看精确数值及最近采收 |
| 永久人物 ID、年龄、健康 | ID 哈希决定稳定外观和格内站位；儿童与低健康状态可见；点击查看同一档案和家谱 |
| 目的地、路径与执行阶段 | 真实坐标插值移动；选中显示后端缓存路径和目的地；篮、斧、镐、锄、施工/制作锤、书本与休息标志区分活动，携带物与数量可核对 |
| 材料支付、劳动与工程进度 | 未付款场址、材料堆、地基、框架、主体、封顶；详情列出最近劳动、参与者、材料和坐标；未建成无收益 |
| 建筑类型、耐久、作物与使用 | 茅草住所、架高粮仓、开放工坊、学舍、分行农田；作物生长、损坏裂纹和遗址；使用者与计数来自实际执行 |

场景按已有状态显示，未改写旧人物 ID、家庭、建筑坐标或施工进度。新世界没有成熟建筑；初始物资垫是已有执行器使用的公共储藏地点，不能算作建成粮仓。不绘制没有实际机制与记录支持的道路、战争、贸易线路或组织成果。

## 执行凭据与用途

`Person.lastExecution` 保存最近实际采出、入库、到场劳动、播种、照料、学习或休息地点；包含日期、小时、坐标、数量与关联计划。`Tile.lastHarvest` 保存最近一笔采出，`Plan.lastLabor` 保存最近劳动。这些可选字段随存档保存，读取旧世界不补造历史。

这些是最近执行凭据，不是完整的逐小时历史归档。原有工程、事件、人物终身档案和资源账本继续独立保存。建成时记录历史，收益只取 `condition > 0` 的真实建筑。材料不足按原机制失败并记录；付过款的失败工地与倒塌建筑保留遗址，不虚构维修、废弃或重建行为。

住所提供集体庇护容量和休息地点；粮仓增加食物容量并可接收入库；工坊为到场工具制作与试验提供 15% 劳动效率；学舍需要教师学生到场并扩展单次传授容量；农田需要种子食物、到场照料与 90 天生长，收获也需要人员到场。

仍为 24×16 地块、1×1 建筑占地、64 人上限、集体库存；人物允许同地块重叠，以 ID 固定格内站位。未模拟建筑室内、私人住房分配、逐根材料运输、完整生理昼夜或多文明战争。学习图标表示到场/家庭学习活动，是否实际掌握知识须查档案与传承事件。

建筑地块仍保留旧存档中的自然资源，角标可点击查看，不因换画面清零或伪装成采伐。尚未模拟逐株清场。休耕与育林现在选择实际目标地块，并仅在人员到场完成后恢复同一坐标，记录恢复前后肥力与计划 ID；不再在别处劳动、远程恢复另一块地。

## 导航与镜头

保留 `/ai-town/` 基础路径。工作台选择及标签使用浏览器历史；前进后退重新按 URL 读取。聊天小镇有两个明确返回入口，独立携带文明 ID，禁用本地存储时仍能从 URL 返回。没有有效选择不会创建世界、载入演示或自动选择第一个普通世界。

场景以 64 像素表示一个原有逻辑地块，未改变保存坐标。新镜头使用单独本机键，旧镜头设置仍保留。桌面和手机默认按人物可读尺度观察；可拖动、缩放和全图。定位/跟随避开顶部和详情；手机详情打开时暂时收起底部辅助控件，关闭即恢复。

## 可选择的真实演示

世界选择器中“演示·专属文明·”包含自然起点、住所地基、框架、主体、封顶及建成使用分支。同一个 `plan22` 在模拟第 16、18、26、33 天分别存下施工阶段，第 36 天建成 `b25`，第 46 天已有 8 次使用。界面日历从第 1 天显示，因此 UI 天数比内部 `day` 多 1。

`npm run civilization:world-demo` 使用已有小时执行器与明确标注的规则决策生成；不注入库存、人口或进度，不调用模型，不覆盖旧演示。生成记录位于 `.runtime/civilization/world-correction-demo.json`，重复运行会复用这份运行凭据。

另有“成熟聚落与传承（旧快照分支）”，来自旧知识文明的“长期规则运行验收快照”（day 19800），五类建筑齐全、累计 34 次出生/12 次死亡；父世界和原命名快照不变。
