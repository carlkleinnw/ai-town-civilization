# AI 人类文明演化模拟器：第一阶段

2026-10-26 更新：文明世界改用专属地形、资源、建筑与工地渲染器；原聊天小镇顶部增加返回工作台/文明世界的明确入口。人物、建筑及地块详情补充 ID 和最近执行凭据，无有效文明选择时不再自动回退到第一个普通世界。状态对应表、演示与边界见 [专属文明世界](./CIVILIZATION-WORLD.md)。

这是基于原 AI Town 的可运行改造。新增的文明世界与原聊天小镇分开存储，原世界、聊天、记忆和 Windows 启停入口保留。默认主页面为全屏像素世界；详细管理通过独立工作台进入，原聊天小镇入口继续保留。

## 直接开始

1. 保持 Windows Ollama 服务运行，双击根目录的 `Start-AI-Town.cmd`。
2. 打开 [文明观察台](http://127.0.0.1:5173/ai-town/)。首次创建世界时，输入种子、初始人数和发展策略，选择两组独立模式。
3. 新局默认以 1×运行（若已有 3 个运行世界则创建为暂停）。1×默认现实 120 秒对应模拟 1 天，每 5 秒执行一个模拟小时。工作台可修改正常日长；倍速统一影响行动与日终结算，达到计算上限会显示限量推进。
4. 点击“工作台”进入 `/ai-town/workbench/`。可主动选择“演示·小时行动·生存（规则5年）”“演示·小时行动·知识（规则5年）”或“演示·第一间住所施工中”；前两者展示真实连续运行结果，后者可继续观察施工。另有新的“小时行动”55 年实验（允许自然提前灭绝），旧 55 年存档保留。名称带“验收”的世界是独立验证实验。
5. 退出时可先暂停，再双击 `Stop-AI-Town.cmd`。停止器核对本项目进程，保留已有 Ollama 服务。

命令行入口：`npm run dev:windows`。现有依赖和模型均直接复用，无需安装、Docker、WSL 或付费服务。模型沿用 `.env.defaults` 的 `qwen3.5:4b`；旧小镇记忆继续使用 `embeddinggemma:300m`。

## 策略怎样实际执行

七种预设分别偏向生存、农业、知识、探索、交换、防卫、生态；也能自定义各行动权重、食物储备目标和自然采收比例。权重改变的是劳动安排与选择顺序，不直接增加产出。缺少木材、石料、食物、知识、地点或劳动力时，建设不会开始。

人物按身体状况、性格、价值倾向、兴趣和家庭情况参与集体计划，也会自行采食或休息。住所需要材料和工期；农田需要种子投入、照料劳动和 90 天生长期；工具会磨损；试验消耗材料且可能失败；教学需要活着的知识持有者；议事和守卫要经过讨论接受，可能失败。建筑会逐渐损耗，约 45 年后需要重建。

计划依次记录提议、计划、执行、完成/失败。提议文字不会产生建筑。地图、人物、资源统计与执行记录来自同一个 Convex 世界状态。点击人物、地块、建筑或施工框可以查看详情，老建筑的施工记录即使已归档也能查阅。

## 两组设置可以任意组合

| 决策权 | 行为 |
|---|---|
| 人工决策 | 关键节点在面板等待人工选择；日常生存照常结算 |
| AI 自主 | 关键节点排队交给本地模型，普通执行由规则持续处理 |
| 混合模式 | 日常交给 AI，指定节点类型交给人工；类型可自行勾选 |

| 策略持续方式 | 行为 |
|---|---|
| 长期贯彻 | 核心策略锁定。模型即使建议换向，也只记录矛盾，不能自行更换 |
| 节点调整 | 在年度方向/危机节点重新评估。AI 决策权下可在这些节点改向；人工节点可以选新方向 |
| 自主演化 | AI 在关键决策中可以基于条件提出新取向，记录时间与理由 |

“方向设置”随时可以修改两组模式、核心策略、混合节点和截止日。变更原因必填，审计保留日期、现实时间、操作者和前后值。模型迟到的输出不能覆盖新设置。已经开工的工程保留原策略来源与已支付成本。

## 人物和代际

人物有独立身份、出生日期、性格、技能、价值倾向、兴趣、目标、身体状态、家庭和经历。出生需要成年伴侣、健康、情绪、食物余量、住所和生育间隔；达到在世人口上限后不再出生。孩子混合随机与父母能力倾向，出生时不直接拥有父母技术，必须实际学习。

死亡减少人口和劳动力，影响亲属情绪与伴侣关系。已故人物进入独立档案，家谱保留身份引用。最后一位知识持有者死亡会造成知识失传，后续可通过重新试验恢复。人物面板保留最多 24 条经历，家庭与学习事件优先保留；世界事件档案继续保存。

## 模型与规则边界

小时规则负责移动、采集、搬运和现场劳动；日终处理消耗、老化、出生死亡、磨损和自然资源再生。模型负责集体关键节点：大约每 90 天或发生食物危机时调用。普通执行不调用模型；多个标签页只订阅，不各自推进时钟。

模型只能返回候选行动、简短中英文理由和允许模式中的策略建议。输出先检查字段、候选项和长度，再由规则检查当前可行性。模型没有通用世界补丁、人口写入、库存写入或直接创建成果的接口。每次最多尝试两次，每次 22 秒；失败后明确回退为规则建议，并记录尝试次数和错误。

相同模型与完整决策上下文可命中有效期一天的缓存；会核对完整上下文，避免短哈希碰撞，日志标注缓存。缓存上限 1000 条。每个世界同时只有一个有效模型租约，设置变更与人工接管使旧结果失效。

## 存档、分支和比较

每次心跳与结算事务保存到 E 盘的 `.convex/local/default`，包括日内小时、小数时间预算、倍率与正常日长。关闭网页不会停止在线后端的模拟；停止后端后不按离线时长追算。重启保留“运行/暂停”状态，运行的世界继续下一批结算，暂停的世界维持原状。

命名快照可以恢复为新分支，不覆盖原世界。分支保留 PRNG 状态、库存、人物、知识、建筑、制度与模式；父世界后来的变化不会改写分支。历史同时使用日期和事件序号截断，避免同一天的后续干预串入分支。

“实验比较”提供人口、食物、健康、知识、建筑、土地肥力的实际采样曲线和多维表格，不合成总分。状态中最多保留 160 个跨时间范围的真实样本，较早样本降采样；完整月度记录另行归档。相同种子重现相同初始条件，但不同策略会消费不同随机序列，后续随机事件不保证逐个配对。

“导出当前快照”导出当前运行状态和最近记录，供检查使用；它不包含整个数据库归档，也未提供通用 JSON 导入。跨电脑迁移需要停止项目后复制完整 `.convex` 目录，并保留源代码版本与模型配置。

## 人工干预

可注入食物、木材，持续改变降雨/干旱系数，或强制安排一项计划。原因必填，注入单独记账。强制计划仍受材料、地点、人员和工期约束，完成结果标记人工来源。发生干预后的世界和新计划也会标注实验路径已受人工影响，不能当作完全自主发展的证据。

长程生存演示在 55 年验收快照之后收到过 20 食物的人工测试补给，时间没有继续推进；账本和历史保留这次人工操作。`.runtime/civilization/long-run-results.json` 和该世界的“长期规则运行验收快照”保留补给前的结果，可恢复为独立分支。

## 第一阶段边界

- 地图 24×16，在世人口上限 64，初始 4–32 人；最多同时运行 3 个世界，保留最多 100 个实验与每个世界 100 个命名快照，分支深度最多 12。
- 年长 360 天。生育是受条件限制的概率规则，未模拟怀孕过程；家庭重点实现伴侣、亲子、代际学习和丧亲影响，尚无复杂社交网络、财产继承和阶级系统。
- 三项集体知识、五类可建设设施和十六类行动。建筑布局与生产是简化规则，库存集体共享，人物可以在同一地块重叠。
- 交换来自明确标注的环境商队；军事取向目前落实为工具、探索和守卫轮值，尚无完整多文明战争、外交和领土系统。
- 新人物日常行为与目标执行主要由规则驱动。模型用于集体关键决策，尚未接入每人独立的模型对话、创意制度生成或旧小镇向量记忆互通。
- 当前技术目录有限，但不会因技术完成或到达某年代而强制结束。可以继续建设、生产、衰退或灭亡；可选截止日由用户设置。

继续扩展应增加可验证的行动配方、条件与执行器，再扩展策略权重，不能让模型文字直接写入成果。

架构顺序见 [CIVILIZATION-PLAN.md](./CIVILIZATION-PLAN.md)，实际验收见 [CIVILIZATION-VERIFICATION.md](./CIVILIZATION-VERIFICATION.md)。

## 全屏世界与工作台

世界页支持拖动、滚轮与双指缩放、全图定位；右下角可选择人物、建筑和施工现场。人物可定位跟随，点击实体打开可关闭的详情。像素外观按人物永久 ID 选择，不随出生死亡后的列表顺序变化。窗口和手机布局保留中文可读字体。地图、统计、家谱和记录都读取同一个后端状态。

工作台的世界、面板写入地址，刷新与切换页面不创建新世界。地图视角按世界本机保存；隐私模式禁用本地存储时仍可通过世界 URL 访问。演示世界不会在没有明确选择时自动载入。

原始起点为 160 食物、基础采集/协作/简易制作能力，没有建筑、工具、集体知识或制度。时代名称基于住所、知识、实际农业产出和组织条件，条件丧失时允许倒退。现有存档的原日期、人物和成果保留。

资源采出后记入人物携带，运回才可用于共享库存；账本包括携带中物资。建设材料在开工时一次性投入，随后必须由到场人员付出劳动。材料准备、地基、框架、墙体、封顶与完工有对应画面；工坊提升现场制作/试验劳动效率，学舍提供真实教学场所。使用次数从本轮后开始记录，不能把旧档中未记录的活动当成已验证行为。

当前仍采用 1×1 建筑与集体储藏，不模拟逐件建材运输、完整昼夜作息、怀孕、私有财产、多文明战争外交或领土分裂。建筑遗址在热状态中最多保留最近 80 处；完整历史仍归档。详细兼容与时钟说明见架构文档。
