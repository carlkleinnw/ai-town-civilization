## 明确边界

本次验证的是本地数据库、恢复和浏览器行为，未证明长期稳定运行或未来磁盘日增长率。79% 是内存中序列化负载对比，不是物理磁盘增长率。主库不会因压缩变成永久恒定大小，完整历史仍会增加。

生产旧版本回收参数未调整：六小时窗口试验因旧后端启动扫描未就绪，没有形成有效回收验证。原大库曾在 360 秒超时，延长等待后成功启动；重建库再次通过原 Windows 启动器就绪，函数部署耗时约 2.5 秒。这个部署耗时不是整套启动耗时，也不作为长期性能承诺。

旧后端启动读取完整技术历史的问题对应官方 [issue #593](https://github.com/convex/convex-backend/issues/593)；候选修复见 [PR #539](https://github.com/convex/convex-backend/pull/539) 和 [提交 2ffe557](https://github.com/convex/convex-backend/commit/2ffe557)。本次没有安装未发布的后端补丁，也没有引入 Docker/WSL、独立数据库或云存储。

临时恢复/回收验证副本仍保留在 `E:/AI_town/tmp/storage-*`：自动安全检查拒绝了递归清理，只返回 `blocked by policy`，没有具体原因。未绕过该限制；所有临时后端均已停止，正常服务只使用项目自己的 `.convex`。
